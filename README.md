# Sentence Embedding Using Transformer

##  Project Overview

This project uses a **Sentence Transformer** model to convert sentences into numerical vectors called **embeddings**.

It then uses **Cosine Similarity** to identify sentences that have similar meanings.

##  Objective

* Convert sentences into embeddings.
* Understand the semantic meaning of sentences.
* Calculate similarity between sentences.
* Display semantically similar sentence pairs.

##  Technologies Used

* Python
* Sentence Transformers
* Scikit-learn
* `all-MiniLM-L6-v2`

##  Model Used

```text
all-MiniLM-L6-v2
```

The `all-MiniLM-L6-v2` model is used to convert sentences into **384-dimensional embeddings**.

##  How It Works

### 1. Load the Sentence Transformer Model

```python
model = SentenceTransformer("all-MiniLM-L6-v2")
```

The Sentence Transformer model is loaded.

### 2. Provide Input Sentences

Example sentences used in the project:

```text
I like apples.
I love eating apples.
I am going to school.
I go to college every day.
The cat is sleeping.
The dog is playing.
I like tea.
I enjoy drinking tea.
```

### 3. Generate Embeddings

```python
embeddings = model.encode(sentences)
```

Each sentence is converted into a numerical vector called an **embedding**.

### 4. Calculate Cosine Similarity

```python
similarity = cosine_similarity(embeddings)
```

Cosine Similarity is used to measure the similarity between the sentence embeddings.

### 5. Display Similar Sentences

The program displays sentence pairs whose similarity score is greater than `0.5`.

##  Key Concepts

### Embedding

An embedding is a numerical representation of a sentence that captures its semantic meaning.

### Sentence Transformer

Sentence Transformer converts sentences into numerical vectors that can be compared based on their meaning.

### Cosine Similarity

Cosine Similarity measures the similarity between two vectors.

A value closer to **1** generally indicates greater similarity between the vectors.
